# TandaPlus

Plataforma de ahorro comunitario digital.

## Estructura
- `frontend/` — Flutter (web, android, iOS)
- `backend/` — Dart Frog (API REST + WebSockets)

## Requisitos
- Flutter SDK
- Dart SDK
- SQL Server

## Configuración
1. Copia `.env.example` a `.env` y llena las variables
2. `cd backend && dart pub get`
3. `cd frontend && flutter pub get`
